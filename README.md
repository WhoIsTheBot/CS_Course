## Лабораторна робота №8
## Варіант 1

---

## Опис завдання

Реалізувати з використанням Data Flow. Перемножити 2 прямокутні матриці, якщо це можливо. Кожен елемент матриці повинен обраховуватися в потоці. Врахувати інформацію, що кількість рядків та стовпців можуть бути як завгодно великими (наприклад: 1000x100, 100x7000). Реалізувати метод для генерації матриці за заданою кількістю рядків та стовпців. Програма повинна мати можливість завершити роботу на вимогу користувача.
